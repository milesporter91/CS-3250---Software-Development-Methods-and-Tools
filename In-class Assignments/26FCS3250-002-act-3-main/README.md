# Instructions: Part 1

Work in pairs to create a high-level requirements specification list for a web application that allows users to save cooking recipes.

* Write each requirement in plain English, using just one sentence.
* Classify each requirement as either a user or system requirement.
* If it's a user requirement, further classify it as functional or non-functional.
* Be prepared to share your list with the class.

User Requirements:
	Functional:
	•	User should be able to input a recipe via a form
	•	User should be able to save recipe to web app
	•	User should be able to log in using unique username/password
	•	User should be able to search for recipes by keyword
	•	User should be able to edit their own recipes
	•	User should be able to add photos to recipe
	•	User should be able to delete their own recipes
	Non-Functional:
	•	User should be able to access their library while offline
	•	User should be able to modify visibility or recipes
	•	User should be able to access recipes from previous sessions
